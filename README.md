# 🚗 حاسبة قطة الرحلات — تطبيق جوال (آيفون وأندرويد)

نسخة تطبيق جوال حقيقي (React Native / Expo) من برنامج "حاسبة قطة الرحلات" الأصلي.
نفس الميزات بالضبط، لكن بدون خادم — كل البيانات تُحفظ على جهازك مباشرة.

## ✨ الميزات

- 🧳 إدارة رحلات متعددة (إنشاء، اختيار، حذف)
- 👥 إضافة مشاركين بنسبة قطة (كاملة / نص / نسبة مخصصة)
- 💰 تسجيل التكاليف لكل مشارك مع وصف اختياري
- 🔄 حساب من يدين لمن تلقائيًا (خوارزمية تبسيط الديون نفسها من النسخة الأصلية)
- 📊 ملخص شامل: الإجمالي، السعر لكل وحدة قطة، تفاصيل كل مشارك
- 📤 مشاركة النتائج (زر مشاركة عام + واتساب/تيليجرام/إيميل/نسخ)
- 💾 حفظ محلي دائم على الجهاز (يعمل بدون إنترنت بعد التثبيت)

│   └── theme/colors.js        الألوان والهوية البصرية

## 🚀 التشغيل والتجربة الفورية (على جوالك، بدون Mac أو حاسوب قوي)

1. ثبّت [Node.js](https://nodejs.org) على حاسوبك إن لم يكن مثبتًا.
2. ثبّت تطبيق **Expo Go** من App Store أو Google Play على جوالك.
3. افتح Terminal (أو CMD) داخل مجلد المشروع ونفّذ:

   ```bash
   npm install
   npx expo start
   ```

4. سيظهر رمز QR في الطرفية. امسحه بكاميرا الجوال (آيفون) أو بتطبيق Expo Go (أندرويد).
5. التطبيق سيفتح فورًا على جوالك جاهزًا للتجربة والتعديل الفوري (Hot Reload).

> ملاحظة: جوالك وحاسوبك لازم يكونوا على نفس شبكة الواي فاي.

## 📦 بناء التطبيق الحقيقي للنشر في المتاجر (App Store / Play Store)

هذه الخطوة تحوّل المشروع إلى ملف `.ipa` (آيفون) و `.apk`/`.aab` (أندرويد) فعليين، باستخدام خدمة **EAS Build** المجانية من Expo (لا تحتاج Mac حتى لبناء نسخة آيفون):

```bash
npm install -g eas-cli
eas login          # أنشئ حساب مجاني على expo.dev إذا ما عندك
eas build:configure
eas build --platform android   # لبناء ملف أندرويد
eas build --platform ios       # لبناء ملف آيفون
```

- بناء الأندرويد تقدر تحمّله وتثبّته مباشرة أو ترفعه لـ Google Play (حساب مطور Google: رسوم لمرة واحدة 25$).
- بناء الآيفون يحتاج **حساب Apple Developer** (99$/سنة) لرفعه فعليًا على App Store، لكن EAS يبنيه لك بدون Mac.

## ⚠️ إذا ظهرت رسالة "Project is incompatible with this version of Expo Go"

هذا المشروع مضبوط على **Expo SDK 54**، وهو النسخة اللي تطبيق Expo Go على متجري App Store وGoogle Play يدعمها حاليًا (شركة Expo عندها تأخير من آبل بالموافقة على تحديثات أحدث للتطبيق، فتطبيق Expo Go المنشور بالمتجر يفضل فترة طويلة عالق على نسخة SDK قديمة نسبيًا).

إذا واجهت هذه الرسالة رغم ذلك:

1. تأكد إن تطبيق **Expo Go** نفسه محدّث لآخر إصدار من المتجر.
2. افتح Expo Go وشوف رقم الـ SDK اللي يدعمه (عادة يظهر في الصفحة الرئيسية أو صفحة الإعدادات داخل التطبيق).
3. إذا كان رقم مختلف عن 54، خبرني بالرقم وأعدّل المشروع ليطابقه — تعديل بسيط بخط واحد في `package.json`.

## 🔧 ملاحظات تقنية

- **التخزين محلي بالكامل** عبر `AsyncStorage` على كل جهاز — لا يوجد خادم أو إنترنت مطلوب لتشغيل التطبيق، والبيانات لا تُشارك تلقائيًا بين الأجهزة.
- إذا احتجت مزامنة البيانات بين عدة أجهزة مستقبلًا (كل المشاركين يشوفون نفس الرحلة)، هذا يتطلب إضافة خادم أو خدمة سحابية (مثل Firebase) — تقدر تطلبها كخطوة تالية.
- الأيقونة وشاشة البداية جاهزتان بنفس هوية الألوان الأصلية (بنفسجي متدرّج).
- الواجهة بالكامل بالعربية ومحاذاة لليمين، لكن اتجاه التنقل بين التبويبات يبقى تقنيًا من اليسار لليمين (RTL كامل على مستوى تخطيط الشاشة يتطلب خطوة إضافية قابلة للإضافة لاحقًا إذا رغبت).
