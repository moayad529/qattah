قسّم مصاريف رحلتك بسهولة

## الوصف (Description)

```
قطة تطبيق بسيط يخلّيك تنسى مشكلة "مين دافع كم" في رحلاتك ونزهاتك مع الأصدقاء والعائلة.

✅ سوّي رحلة جديدة لكل خرجة أو سفرة
✅ ضيف المشاركين وحدد نسبة كل واحد من "القطة" (كاملة، نص، أو نسبة مخصصة)
✅ سجّل كل مصروف أول بأول، وعدّله متى تبي، أو ألصق رسالة البنك ويقرأ التطبيق المبلغ والمتجر
✅ التطبيق يحسب تلقائيًا مين يستحق يدفع لمين، وبكم بالضبط
✅ إحصائيات الرحلة، وتصدير PDF، ومشاركة الملخص بضغطة وحدة
✅ اختر عملة كل رحلة، ووضع ليلي مريح للعين
✅ شارك الرحلة بكود مع أصحابك بصلاحيات: مشاهد، مدخل فقط، أو مدخل ومعدّل — بدون حسابات أو إيميلات

بياناتك تُحفظ على جوالك. والرحلات اللي تختار مشاركتها تُحفظ نصوصها فقط وتُحذف تلقائيًا بعد 90 يوم بدون نشاط.

مناسب لرحلات البر، السفر الجماعي، خرجات الأصدقاء، وأي موقف تحتاجون فيه توزيع المصاريف بعدل وبدون حرج.
```
